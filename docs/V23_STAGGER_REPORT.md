## 3. 冻结准则三条件判定（iter=5 档）

- (a) 提前跳出：19 组无一发生（含 (5,0.1)/(5,1.0) 假设档，passes 全满档）——**不满足**。
- (b) |ΔTmax| ≤ 10%：iter=5 为 -9.59%（依据仅本算例敏感性线索，非误差定论）——满足。
- (c) 所有区间收缩：不满足（区间3 有不收缩档）。

→ 按准则第 2 条：**不能推荐固定 tol**；按第 3 条验证规则：
**0.1–1K 预注册假设不成立**。
结论方向为"不建议启用固定 tol"（准则认可的合法研究结论）。

## 4. 敏感性观测（与收敛判定分开，仅本算例线索）

- Tmax 对 stagger_iter 高度敏感且非单调：
  iter=1 → 1499.60°C；iter=2 −25.25%；iter=3 −6.91%；
  iter=4 −20.82%；iter=5 −9.59%。E_in 同向同量级。
- A1 级（4 区间）敏感性比轻算例（1 区间，-8.34%）更大且振荡；
  定点迭代在 3/4 个区间远未收敛（d5 数十至数百 K）。
- 区间3（末区间，最热点）出现不收缩，与预登记的居里穿越区间（μr 塌缩）
  可能不收缩的疑点方向一致——**机理层面属推断，标为待证实**；
  脚本未记录 frac_above_Tc/μr 逐区间值，不做机理断言。
