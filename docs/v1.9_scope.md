## 1. 目标

给 v1.7/v1.8 的 Tet10 节点型 A-V **相量**求解器加非线性磁材料能力：
铁磁元件的磁阻率 ν 随单元 |B| 变化（ν = ν(|B|)），用 Picard（定点）
迭代 + 松弛求解。等温、无温度耦合（μr(|B|,T) 与居里点留 v2.0 候选）。

2D 先例：BIG-M10（仓库 tests/test_bench_nonlinear_bh.py /
~/workspace/big_m10/）已在 axi 框架上做 μr(|H|,T)+居里 770 ℃ 的
Picard 迭代；本版把同一物理口径搬到 3D Tet10 A-V 相量框架。

## 2. 提法

- 基方程与 v1.7 相同（e^{iωt} 相量、A-V 块系统），唯一变化是
  curl-curl 块的 ν 逐单元取值：K = K(ν_e)，ν_e 为第 e 个单元的
  割线磁阻率。其余块（σ 质量 M、耦合 G、V 刚度 S）与材料无关，
  只装配一次。
- 材料律（与 BIG-M4/M10 同一曲线，**模型假设**，非实测材料数据）：
  直流磁化曲线取 M(H) = Ms·tanh(H/H_REF)，其中饱和磁化
  Ms = Bsat/μ0，Bsat = 1.9 T（饱和极化），低场磁性部分
  MU_MAG0 = 200，H_REF = Ms/MU_MAG0。割线相对磁导率

      μr(|H|) = 1 + MU_MAG0 · tanh(h)/h，  h = |H|/H_REF

  （h→0 时 μr → 201；h→∞ 时 μr → 1）。本版等温，M10 的居里
  tanh 温度开关 step(T) 恒取 1，不出现在公式里。
  相量口径：|H|、|B| 均取复相量幅值（峰值约定，与 v1.7 的
  Q = ½σ|E|² 时间平均口径一致）；每轮由当前解的单元 B 相量算
  |B|，由割线关系 |H| = ν_e·|B|（ν_e 为本轮所用割线值），再由
  曲线得目标 μr 与目标 ν。这是非线性相量问题常用的割线/等效
  μ 近似（只保留基波、不产生谐波），不是时域非线性的精确解，
  报告与文档均按此口径表述。
- 适用元件：由 `iron` 谓词（callable(x,y,z)->bool，按质心判定，
  与 σ 的质心采样口径一致）标出的铁磁元件；其余元件 ν 保持
  线性求解器的给定值（默认 1/μ0）。
- Picard 迭代：初值 ν_e = 1/(μ0·201)（铁磁元件低场值）；
  每轮：装配 K(ν_e) → 解线性相量系统 → 算单元 B → 目标 ν →
  松弛更新 ν_e ← (1−relax)·ν_e + relax·ν_target（默认
  relax = 0.5，与 M10 一致）。
- 收敛判据：|B| 幅值场的相对变化
  ‖|B|_new − |B|_old‖₂ / ‖|B|_new‖₂ < tol（默认 tol = 1e-3），
  或达到 max_iter（默认 50）。范数只取铁磁元件子集：空气区 |B|
  由外加场决定、几乎不随 ν 动，全域范数会掩盖非线性区的运动
  （原型实测：全域 rel 已 <1e-3 时表面 μr 尚在松弛中途）。返回完整迭代史（每轮 rel_dB、
  总焦耳功率 P、每轮实际所用 ν 对应的解），不收敛时如实置
  converged = False 返回（不抛异常、不假装收敛）。

## 3. 实现

新入口（不改 v1.7/v1.8 既有函数的数值行为）：

- `bh_secant_mu_r(Hmag, bsat=1.9, mu_mag0=200.0)`：上面的割线
  μr 曲线（M10 的 mu_mag_of_H 等温版），向量化。
- `solve_eddy_current_nonlinear_tet10(...)`：签名与
  `solve_eddy_current_tet10` 对齐（mesh / sigma / omega /
  B_applied / J_s / boundary / a_bc / gauge_eps / permc_spec），
  另加 iron / bsat / mu_mag0 / mu_init / tol / max_iter / relax。
  返回 (a, v, info)，info 含 iterations、converged、rel_dB 史、
  P 史、末轮 μr_e 与 ν_e（逐单元）。
- K(ν_e) 的重装配在本模块内新写 `_assemble_curl_curl_tet10_nu`
  （逐单元 ν 数组版，与 assemble_tet10_av 中 K 的构造同式）；
  M/G/S 复用 `assemble_tet10_av`（以 ν=1 装配一次、弃其 K）。

## 4. 验证设计（tests/test_tet10_em_nonlinear.py，全部"仿真输出"）

几何：有限长铁柱（圆柱，轴沿 z）在空气盒中、外加均匀 AC 场
（B_applied 路径），网格沿用 D1_CYL 的构造方式但缩小规模以便
本机 2 核跑小网格；σ 与频率取使趋肤深度与半径可比的量级。

1. **线性极限自洽**：mu_mag0 = 0（曲线退化为 μr ≡ 1）时，
   非线性入口的结果与 `solve_eddy_current_tet10`（ν=1/μ0）
   的 a 场相对差 < 1e-6（断言）。另测 iron=None（无铁磁元件）
   同样与线性解一致。
2. **饱和方向性**：同几何同激励，比较 (i) 非线性解、(ii) 恒定
   低场 μr = 201 的线性解、(iii) μr = 1 的线性解。断言：
   非线性解总功率 P 严格介于两者之间（P(μr=1) 与 P(μr=201)
   之间）；铁内表面层单元的 |B| 被曲线钳制——非线性解中铁内
   最大 |B| 小于恒定 μr=201 线性解的对应值（后者无饱和、
   |B| 随 μr 线性放大）；末轮铁内 μr_e 分布有梯度（表面
   μr 低于深处，方向与趋肤+饱和一致）。
3. **与 2D M10 的量级一致性（非紧基准）**：取 M10 算例 A 的
   可比参数（同半径圆柱、同 σ 量级、同频、同量级激励的
   等效构造），3D 有限长柱中段（|z| 小于半长的中截面附近
   单元）的单位长度功率与 M10 的 axi 长柱 P/L 只作量级
   一致性检查（比值落在 0.2–5 的宽带内即通过），并如实注明：
   3D 是有限长（端部效应）、激励方式与 axi 的 Neumann H0
   口径不同、网格粗细不同，**非紧基准**（参照 v1.7 线圈例
   的标注口径）。
4. **Picard 收敛性**：强饱和工况下迭代收敛（converged =
   True），rel_dB 史有界且末值 < tol；迭代全程 P 有界
   （不发散、不出现 NaN）。
5. **回归**：tests/test_tet10_em.py、
   tests/test_tet10_em_transient.py、tests/test_inductance.py、
   tests/run_all_benchmarks.py 全部 rc = 0。

## 5. 不做事项

- 不做时域非线性（谐波、磁滞、涡流-磁滞耦合均不做）；不做
  温度耦合与居里点（留 v2.0 候选）；不做 Newton 法（Picard
  收敛性如实记录，强饱和下若需更多轮次/更小松弛，按实测写）。
- 不改 v1.7/v1.8 既有函数的数值行为；新功能只用新入口。
- 不跑重算例：本机 2 核只跑小网格；家机队列与本版无关。
