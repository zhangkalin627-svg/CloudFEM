# CloudFEM v2.0 范围定义（2026-10-22）

数值均为"仿真输出"。本范围由缪斯按管家 2026-10-22 07:35 批复（v1.8 起
"由缪斯直接开工、自定版本范围"）自行定义；v1.9 范围文档 §5 已把
"温度耦合与居里点"列为 v2.0 候选，本版即做它。

## 1. 目标

把 v1.9 的三维非线性 B-H 相量涡流（Tet10 节点型 A-V、割线 μ Picard）
与温度耦合：铁磁元件的割线磁导率 μr = μr(|B|, T) 带居里点，电导率
σ = σ(T)，与 Tet10 瞬态热传导做交错（staggered）耦合，使感应加热中
"表面先过居里点 → 表层 μr 塌陷到 ~1、趋肤层变厚、功率向深处再分布"
这条链在 3D 框架里跑出来。等温（T 恒定低温）时新求解器退化回 v1.9。

## 2. 物理口径（与 BIG-M4/M10 对齐，全部为解析模型假设，非实测材料数据）

来源：仓库 `tests/test_bench_nonlinear_bh.py`（BIG-M10）与
`~/workspace/big_m10/big_m10_nonlinear_bh.py`，两者材料律逐字一致，
本版照搬以下形式（常数可由参数覆盖，默认即 M10 值）：

- 居里开关（M10 `step_T`，BIG-M4 原式）：

      step(T) = 0.5 * (1 - tanh((T - Tc) / W_STEP)),
      Tc = 770 °C,  W_STEP = 15 K

  T ≪ Tc 时 = 1，T = Tc 时 = 0.5，T ≫ Tc 时 = 0（float64 下
  T = 20 °C 时恰为 1.0、T = 1200 °C 时恰为 0.0，本版原型实测）。
- 磁化律（M10 `mu_mag_of_H` + `mu_r_of_HT`）：

      μr(|H|, T) = 1 + mu_mag(|H|) * step(T),
      mu_mag(|H|) = MU_MAG0 * tanh(h) / h,  h = |H| / H_REF,
      Ms = Bsat / μ0, Bsat = 1.9 T, MU_MAG0 = 200, H_REF = Ms / MU_MAG0

  与 v1.9 的关系：v1.9 的 `bh_secant_mu_r(|H|)` = 1 + mu_mag(|H|)
  （等温、step ≡ 1 版）。本版 μr(|H|, T) = 1 +
  (`bh_secant_mu_r(|H|)` − 1) * step(T)，直接复用 v1.9 函数，
  保证 T 恒定低温时目标 μ 与 v1.9 逐位相同。
- 电导率（M10 `sigma_T`，BIG-M4 原式；**与** induction3d 的
  线性电阻率律 `steel_sigma_of_T` 是两条不同的律，勿混）：

      σ(T) = SIG_LO + (SIG_HI − SIG_LO) * 0.5 * (1 − tanh((T − T_SIG) / W_SIG)),
      SIG_HI = 6e6 S/m, SIG_LO = 1e6 S/m, T_SIG = 550 °C, W_SIG = 150 K

  σ(20 °C) = 5.995738e6 S/m（非恰 6e6；M10 算例 A 等温口径同样用
  σ(20 °C)，本版等温极限验证即按此对齐）。
- 热物性（常数，简化，见 §5）：导热系数 k = 30 W/(m·K)（M10 值）；
  体积热容 ρcp = 7850 × 480 = 3.768e6 J/(m³·K)（M10 的 ρ 与
  cp 基值 480 J/(kg·K) 之积，**不**含 M10 的 cp(T) 基线斜率与
  居里高斯峰——见不做事项）。工件表面绝热（与 M10 算例 B、
  v1.4 链同一短时假设：忽略向空气/线圈的散热）。

## 3. 耦合提法（交错 / 松耦合，M10 算例 B 同口径 + 可选步内定点迭代）

新模块 `cloudfem/physics/induction3d_tet10.py`（驱动模块，与 v1.4 的
induction3d.py 平行；`em3d_tet10.py` 一行不改，v1.7–v1.9 数值行为
由既有回归保证）：

- `solve_eddy_current_nonlinear_tet10_T(mesh, T_elem, ...)`：
  温度冻结下的非线性相量 EM 求解。与 v1.9 求解器同一 Picard 结构
  （松弛 0.5、收敛判据为铁元件子集 |B| 幅值相对变化 < tol、同一
  K 重装配与线性解路径），三点不同：
  (i) 目标 μr 由 μr(|H|, T_e) 给出（T_e 为单元温度，质心口径）；
  (ii) σ 块（M/G/S）按单元 σ(T_e) 装配（铁元件 σ = σ(T_e)，
      非铁元件 σ = 0 即空气；σ 规格由 M10 律唯一确定，不再是
      自由 callable——本求解器专用于钢工件口径）；
  (iii) 支持 `nu_init` 热启动（上一 EM 步的 ν 场作初值）。
  T 均匀恒定低温时 (i)(ii) 与 v1.9（σ ≡ σ(T) 常数）逐位同路。
- `induction_heating_3d_tet10(mesh, ...)`：时间推进驱动。
  工件 = `iron` 谓词标出的元件子集，热求解在其 Tet10 子网格上
  进行（子网格提取 = 元件子集 + 节点重编号，边界面全部绝热）。
  时间步进：
  * 热步长 dt（theta 法，默认 BE）；EM 每 `em_every` 个热步
    重解一次（M10 算例 B：热 dt = 0.01 s、EM 每 0.1 s 更新，
    同一松耦合口径），EM 区间内焦耳热源 Q 冻结为常数；
  * 每个 EM 区间开始：以当前温度场（单元温度 = 子网格节点
    温度的单元均值）做上面的温度冻结 EM 求解（ν 热启动），
    得单元焦耳热密度 Q_e = ½σ|E|²（`total_joule_power_tet10`
    的单元口径，离散 E 精确）；
  * 热推进：源载荷按单元常数 Q_e 精确装配（与
    `assemble_tet10` 的 f 装配同式），theta 步进在子网格上
    进行；K、C 常数（k、ρcp 常数）故系统阵一次分解全程复用；
  * 可选步内定点迭代 `stagger_iter > 1`：对同一 EM 区间，先以
    区间始温度解 EM 并推进，得区间末温度估计，再以该估计
    重解 EM 并从区间始温度重新推进，比较两次区间末温度场，
    最大差 < `stagger_tol` 或达到 `stagger_iter` 次为止
    （接受最后一次推进）。默认 `stagger_iter = 1`（纯松耦合）。
  * 能量对账：E_in = Σ（每个 EM 区间实际采用的 P × 区间时长）；
    焓增量 = ρcp · 1ᵀC₁(T_end − T₀)（C₁ 为 ρcp = 1 的
    `assemble_mass_tet10`）。绝热 + 单元常数源下
    1ᵀC ΔT/步 = dt · P 是离散代数恒等式（1ᵀK = 0），
    对账差应为线性求解精度量级，实测后如实定断言阈值。

## 4. 验证设计（tests/test_tet10_em_thermal_coupled.py，全部"仿真输出"）

几何与 v1.9 同族（铁柱 R = 15 mm、L = 60 mm 在空气盒中，
B_applied 均匀场沿 z，粗网格 h/δ ≫ 1 的既定口径：断言只用
同网格比较、精确退化极限与方向性，不用绝对值紧基准）：

1. **居里开关与材料律单元验算**：`curie_step_T`、
   `bh_secant_mu_r_HT`、`steel_sigma_T` 与测试内独立复写的
   M10 公式（`step_T` / `mu_r_of_HT` / `sigma_T`）在 (H, T)
   网格上逐点对照；锚点：step(20 °C) = 1、step(770 °C) = 0.5、
   step(1200 °C) = 0（float64 恰值）、μr(|H|, 1200 °C) = 1、
   μr(|H|, 770 °C) = 1 + 0.5·mu_mag(|H|)。
2. **等温极限**：T_elem ≡ 20 °C 时 `..._T` 求解器与 v1.9
   求解器（σ ≡ σ(20 °C) 常数、其余参数相同）对比 a 场与 P：
   相对差断言（目标逐位一致，断言按实测取 ≤ 1e-9 量级）。
3. **耦合算例**：小网格铁柱感应加热（H0 = 1e6 A/m、f = 2 kHz、
   t_end = 0.4 s、热 dt = 0.02 s、EM 每 5 个热步一解，
   em_tol = 1e-3 与独立求解器验证同口径），表面层温度穿越
   770 °C。原型实测的两个约束（2026-10-22 本机）：
   (i) 全工件在 ~0.5 s 已整体过居里点（frac>Tc 在 0.4 s 达
   0.99），故算例截到 0.4 s，穿越与再分布窗口完整保留；
   (ii) 耦合 EM 容差**不能**放宽：em_tol = 5e-3 时冷态首区间
   在第 2 轮即"收敛"——强驱动下 rel_dB 先升后降（峰值在约第
   10 轮），松容差会在饱和锋面形成前误停，首区间 P 高估
   13%（5.31e5 vs 4.69e5 W）、表层 μr 147 vs ~6。故耦合
   与独立验证同用 1e-3；0.4 s 全程约 120 轮 Picard，
   新测试文件总时长约 11 分钟（本机实测，如实记录）。
   断言（方向性，阈值按原型实测留裕度后写死）：
   (a) 穿越次序：元件最高温在第 2 区间（t = 0.2 s）已越 Tc
       （实测 890 °C）；表面层（外径向层元件）平均温度首次
       越 Tc 的区间（实测第 3 区间，989 °C）内，芯部带平均
       温度低其 100 K 以上（实测 757 °C，差 232 K）；
   (b) 末段 EM 解的表面层平均 μr 相对首段大幅塌陷
       （居里开关生效），量级按实测；
   (c) 功率深度再分布：焦耳功率径向重心（铁元件按 Q·vol
       加权的平均质心半径）在穿越窗口内下移——各区间最小值
       < 首区间值 × 0.97（表层 μ 塌陷后趋肤层变厚、沉积向
       深处移动；全工件过 Tc 后重心部分回升，故断言取窗口
       最小值而非末值）；（深层带元件仅 2 个，其功率占比
       噪声大，不作断言，原型实测 0.006 → 0.009 仅记录）
   (d) 总功率末段 < 首段之半（原型实测 0.4 s 时约 0.31 倍；
       中间区间有 +0.4% 的小幅上升，不作单调断言）；
   (e) 能量对账相对差按实测量级断言；
   (f) 每个 EM 区间的 Picard 均收敛（converged = True），
       不收敛如实记录并调整参数而非改物理。
4. **回归**：tests/test_tet10_em_nonlinear.py、
   tests/test_tet10_em.py、tests/test_tet10_em_transient.py、
   tests/test_inductance.py、tests/run_all_benchmarks.py
   全部 rc = 0，v1.9 关键数字不变。

## 5. 不做事项

- 不做 cp(T)（M10 的 cp 基线斜率 + 居里高斯焓峰不搬）：ρcp
  取常数。因此穿越时刻与 M10 算例 B 不可直接定量对照，
  只对方向与机理断言，此点在报告中明示。
- 不做 σ(T) 的其他律（induction3d 线性电阻率律不混用）；
  不做热向空气/线圈的散热（绝热工件，短时口径）；
  不做热应力链（v1.4 Tet4 链已有，Tet10 热应力不在本版）；
  不做时域非线性/谐波/磁滞（沿 v1.9 割线基波近似）；
  不做 Newton 法；不改 v1.7–v1.9 既有函数的数值行为。
- 不跑分辨率收敛的重算例：本机 2 核只跑小网格，
  耦合测试总时长按 ~10 分钟内设计（跑不完缩小并如实记录）。
