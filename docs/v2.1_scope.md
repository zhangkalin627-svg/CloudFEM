# CloudFEM v2.1 范围：cp(T) 居里焓峰（2026-10-23 拟，已开工）

状态：分支 `v2.1-cp-enthalpy`（基线 main@4675b9e，v2.0 刚合入）。
头条范围（管家排队口径）：温度相关体积热容 cp(T) = 基线 + 居里高斯焓峰。
v2.1 只做本头条；此前方案稿的 A（Robin 冷却）、B（stagger 判据）、C（材料接口）
仍为候选，不在本版。

一切数字为"仿真输出/仿真结果"，非实测。

## 1. 模型

体积热容 [J/(m³·K)]（`steel_cp_T`）：

    c(T) = rho_cp * (1 + cp_slope * (T - 20))
           + cp_peak_h * exp(-(T - t_curie)² / (2 * cp_peak_w²))

- `rho_cp`：基线体积热容，默认 3.768e6（= 7850×480，沿用 v2.0）。
- `cp_slope` [1/K]：基线斜率，默认 0.0。
- `cp_peak_h` [J/(m³·K)]：高斯峰高，默认 0.0 = 峰关闭。
- `cp_peak_w` [K]：高斯峰宽，默认 25.0。
- 峰中心取 `t_curie`（默认 770°C）。

峰参数（峰宽、峰高）为解析模型假设，非实测数据；峰面积
`cp_peak_h * cp_peak_w * sqrt(2π)` 即磁转变焓（单位体积）。
峰高/峰宽/斜率经 `law_kwargs` 透传（`cp_slope`、`cp_peak_h`、
`cp_peak_w`），在驱动入口 pop，不转发给 EM 求解器。

体积焓 [J/m³]（`steel_enthalpy_T`，相对 t_ref=20°C 的解析积分）：

    H(T) = rho_cp * ((T-20) + cp_slope*(T-20)²/2)
           + cp_peak_h*cp_peak_w*sqrt(π/2)
             * (erf((T-t_curie)/(w√2)) - erf((20-t_curie)/(w√2)))

已验 dH/dT == c(T)（中心差分 1e-10 量级）。

## 2. 离散口径

- 热容矩阵按**单元温度**求值（质心口径，与 v2.0 σ(T)/μr(T) 同粒度），
  经 `_centroid_lookup` 喂给 `assemble_mass_tet10` 的 callable。
- **区间冻结**：每个 EM 区间开始用区间始温度重建 C_iv，区间内
  （含 stagger 多 pass）冻结；A_sys/R_sys 随 C_iv 逐区间重分解。
  与 σ(T)/μr(T) 的 staggered 粒度一致。
- 峰关闭（cp_slope=0 且 cp_peak_h=0，或峰宽≤0）时走 **v2.0 原路径**：
  C 一次装配、一次分解，能量公式逐字 v2.0——逐位复现 v2.0（构造保证）。

## 3. 能量对账口径

- 主对账（离散恒等式，焓形式）：逐区间
  `onesᵀ C_iv (T_末 − T_始) = P_iv · Δt_iv`（onesᵀK=0，绝热），
  累加 `enthalpy_gain = Σ onesᵀ C_iv ΔT_iv`，
  `balance_rel = (E_in − enthalpy_gain)/E_in` 应为线性求解器精度
  （~1e-15 量级）。C_iv 本身已含 cp(T)，左端即离散焓增量。
- 诊断量 `enthalpy_gain_phys = onesᵀ C₁ (H(T_end) − H(T₀))`
  （H 为节点焓解析值）：物理焓增量，与主对账差一个区间冻结
  （方法）误差，dt 小时应为小量；仅作诊断，不参与判据。

## 4. v2.0 约定延续

- em_tol=1e-3 不放宽；numpy 2.5.4 / python3.13 为准。
- 峰关闭逐位复现 v2.0（含能量公式）。

## 5. 未覆盖项（如实标注）

- 本版不做 Robin 冷却边界（仍全绝热）、stagger 判据研究、
  材料律可替换接口（见候选）。
- 冻结粒度的方法误差未做收敛研究（em_every=1 与 v2.0 同口径）。
- 峰参数默认值为模型假设；峰开启的定量行为只断言方向
  （居里穿越延迟），不作绝对值基准。
- k_th 仍为常数（30 W/(m·K)）。

## 6. 逐位复现保证（构造性）

峰关闭（`cp_slope == 0` 且 `cp_peak_h == 0`）时，驱动走
`not cp_varying` 分支，其执行的浮点操作与 v2.0 逐字相同：

- `C_const = assemble_mass_tet10(sub, rho_cp=rho_cp)`（同调用），
- `_make_solver` 内 `A_sys = C + θhK`、`R_sys = C − (1−θ)hK`、
  `spla.factorized(A_sys.tocsc())` 及推进循环（同式），
- 能量 `rho_cp * (ones @ C1 @ (T − T0))`（同式；`ones` 值相同），
- `law_kwargs` 中 pop 掉的 cp_* 键在未传入时不改变转发给
  EM 求解器的参数（传入显式 0 值时反而比 v2.0 更健壮：
  v2.0 会将其透传给 EM 求解器导致 TypeError）。

因此峰关闭即 v2.0 行为，无需数值对照即成立；另有冒烟实测
`balance_rel` 6.5e-16（求解器精度量级）佐证路径正确。
