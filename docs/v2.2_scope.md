## 2. A 的提法与公式口径

### 2.1 冷却模型（简化喷淋口径）

物理口径（**简化模型假设**）：淬火喷淋简化为工件外表面上的
等效对流换热，

    q_loss = h · (T_s − T_inf)        [W/m²，外向为正]

h 为等效换热系数 [W/(m²·K)]，T_inf 为冷却介质温度 [°C]。
h、T_inf 可为常数或空间分布 callable(x, y, z)，**不随时间变化**
（沿 v1.6 `assemble_boundary_terms_tet10` 口径）。这是有意简化：
真实喷淋的 h 随表面温度（沸腾曲线）与时间剧烈变化，本版不做，
在 scope 与 README 中明示"恒定等效 h 的简化口径"。

作用面：工件子网格的**全部外表面**（只被一个子网格元件共用的
面）。不做部分表面选择、不做分时启停（见 §5）。

### 2.2 子网格外表面登记（本版唯一机制风险点，设守门断言）

`_extract_submesh_tet10` 当前不带边界集。v2.2 在该函数内（或
其紧邻 helper 内）由**面发生率**导出外表面：枚举子网格全部
元件面，恰出现一次的面即外表面；把这些面的全部节点（Tet10 面
为 6 节点：3 角点 + 3 边中点）登记为子网格边界集
`sub.boundaries["surface"]`，随后走 v1.6 的
`assemble_boundary_terms_tet10(sub, robin={"surface": (h, T_inf)})`
装配 K_h、F_h，不另写面积分。

设计决定（开发时按此执行，不许两套口径并存）：

- 面集以发生率计数为准，**不许**反过来用"节点是否在表面集"
  推面——薄壁几何（一元件厚）下内部面的 6 节点可能全落在外
  表面节点集里，节点集推面会误收内部面。
- §4 的 S2 对照断言即为此设：驱动实际使用的 K_h、F_h 必须与
  "按发生率面集直接装配同一被积函数"的独立实现逐项对照
  （≤1e-12 量级），且对照几何须包含一元件厚的薄壁情形。
  S2 不过，不许进入算例开发。

### 2.3 离散与步进

- Robin 项贡献刚度增量 K_h 与载荷 F_h = 装配所得
  （`assemble_boundary_terms_tet10` 口径：K_h 为 h·∫N_iN_j，
  F_h 为 h·T_inf·∫N_i，T_inf 空间变化时按其面积分式）。
- 步进改造集中在 `_make_solver`：系统阵改用
  `K_tot = K_th + K_h`，即
  `A_sys = C + θ·h_step·K_tot`、`R_sys = C − (1−θ)·h_step·K_tot`；
  右端每步加 `h_step · F_h`。推导：F_h 不随时间变，theta 加权
  下 `(1−θ)·F_h + θ·F_h = F_h`，故与源项 F_Q 同式、每步恰加
  一份 `h_step·F_h`（不是 θ 份也不是两份）。h 不随时间变 ⇒
  K_h、F_h 一次装配；cp(T) 开启时 `_make_solver` 逐区间以新
  C_iv 重建，K_tot 不变、兼容现有闭包结构。
- Dirichlet 仍不引入（工件表面无温度钉死点）；Neumann 不接入
  驱动（见 §5）。

### 2.4 能量对账口径（本版关键口径变更）

v2.0/v2.1 的对账是绝热离散恒等式（onesᵀK_th = 0）。有冷却后
onesᵀK_h ≠ 0，恒等式变为三方对账（推导：对每热步取
onesᵀ·(theta 步进方程)，源项 onesᵀF_Q = P 精确、导热项消失、
Robin 项给出端点加权散热）：

    E_in = ΔH_disc + E_loss，
    E_loss = Σ_热步 h_step · [θ·q_loss(T^{n+1}) + (1−θ)·q_loss(T^n)]，
    q_loss(T) = onesᵀ (K_h · T − F_h)   [W]

其中 ΔH_disc 沿 v2.1 口径：cp 不变时为 `rho_cp·onesᵀC₁ΔT`，
cp(T) 开启时为 `Σ_iv onesᵀC_iv ΔT_iv`。驱动返回值**新增**
`E_loss`（绝热时恰为 0.0），`balance_rel` 改为
`(E_in − ΔH_disc − E_loss) / E_in`；history 每区间新增
`E_loss_iv`（该区间散热 [J]）与 `loss_rate_end`（区间末
q_loss [W]）。
**纯冷却情形（Q≡0 → E_in = 0）的误差度量另行定义**（R2 修
订）：`balance_rel` 分母为零不可用。S3 及任何纯冷却对账
统一用 `balance_cool = (E_in − ΔH_disc − E_loss) / D`，
D = max(|ΔH_disc|, E_loss)（真实温降情形下两者至少其一
非零；D = 0 视为退化情形、该断言记"不适用"并如实记录，
不许记为通过）。判据 |balance_cool| ≤ tol_rel，tol_rel
与 §4 的 tol_rel 同一纪律：形式现在写死，数值阈值冒烟后
写死进测试与报告。**措辞纪律**：三方对账仍是同一份离散量的代数
对账，按既定"离散恒等式口径"如实标注，不冒充独立检验；独立
检验靠 §4 的 A3 稳态平衡与 S3 交叉路径对照。

与 v2.1 已知限制的衔接（如实预判，§6 详述）：冷却段温变速率
降低、单区间温升变小，居里焓峰在冷却主导阶段更不易被区间
冻结跳过；但加热段的跳过问题不因 A 而解，v2.1 scope §0/§5
的粒度警示在 v2.2 中继续有效、须在新 scope 中重申。

## 3. API 草案（函数签名级别）

改动集中在 `cloudfem/physics/induction3d_tet10.py` 一个模块；
`em3d_tet10.py` 一行不改（沿 v2.0/v2.1 纪律）；
`cloudfem/fem/tet10.py` 原则上不改（复用
`assemble_boundary_terms_tet10`）；若 S2 守门发现
`_boundary_faces10` 的节点集导面与发生率面集不一致，则以
发生率面集为准并在开发报告中记录处置，最终只保留一条装配
路径。新增测试文件一个；`docs/v2.2_scope.md` 由本方案转入。

```python
# ---- 耦合驱动：只加 cooling 一个参数，其余签名与默认不动 ----
def induction_heating_3d_tet10(
        mesh, omega, B_applied=None, J_s=None,
        boundary=None, a_bc=None, iron=None,
        T0=20.0, t_end=1.0, dt=0.01, em_every=5,
        k_th=30.0, rho_cp=3.768e6, method="be",
        stagger_iter=1, stagger_tol=None,
        em_tol=1e-3, em_max_iter=50, em_relax=0.5,
        gauge_eps=1e-6, permc_spec=None,
        cooling=None,            # ← A：None=绝热（v2.0/v2.1 行为）；
                                 #   {"surface": (h, T_inf)}，h/T_inf 为
                                 #   float 或 callable(x, y, z)，
                                 #   恒定不随时间；键只接受 "surface"
        **law_kwargs): ...
```

- `cooling` 键校验：出现 `"surface"` 以外的键 → ValueError
  （子网格只登记了外表面，不许静默忽略未知键）。
- h < 0 → ValueError（负换热系数非物理口径）；h = 0 合法
  （恰退回绝热，见 §4 S1）。

返回值变化（向后兼容地**新增**键，不改既有键语义）：

- `E_loss`：累计对流散热 [J]（绝热时恰为 0.0）；
- `balance_rel`：口径改为三方对账（绝热时 E_loss = 0，
  退回 v2.0/v2.1 口径与数字）；
- `history` 每区间新增 `E_loss_iv`、`loss_rate_end`。

**逐位一致构造保证（判据先行，写死在此）**：`cooling=None`
时驱动必须走与现状逐字相同的浮点路径——实现上以
`cooling is None` 分支跳过 K_h/F_h 的装配与右端项（不许
"装配零矩阵再相加"充数），与 v2.1 的 `not cp_varying` 分支
同一构造纪律。h = 0 时 K_h、F_h 逐项为 0.0，加法不改变
浮点结果，亦应逐位退回绝热数字（S1 双查）。

参数示例（算例用，**模型假设示例值、非实测**）：喷淋简化口径
`cooling={"surface": (5000.0, 20.0)}`（h = 5000 W/(m²·K) 为强
对流示例量级，T_inf = 20 °C 室温水）——示例只用于验证算例的
参数声明，报告引用时必须同时声明其假设属性。

## 4. 验证设计

几何沿 v2.0 同族（铁柱 R = 15 mm、L = 60 mm、空气盒、粗网格
h/δ ≫ 1 的既定口径）：断言只用同网格比较、精确退化极限、
方向性与交叉路径对照，不用绝对值紧基准。新测试文件
`tests/test_tet10_em_thermal_coupled_v22.py`，全部数字标
"仿真输出"。分两层：本地轻量冒烟（开发机、分钟级、只查结构
与退化极限）与交管家云端全量（完整算例 + 全回归，管家在
numpy 2.5.4 / python3.13 新鲜环境复跑为准）。阈值口径沿既定
纪律：判据形式在 scope 先行写死，具体数值阈值按首跑量级留
裕度后写死进测试与报告，不预设拍脑袋数字。

### 4.1 本地轻量冒烟（开发时跑，轻量优先）

| S2 | Robin 装配正确性（守门） | 极小子网格（含一元件厚薄壁几何）上，驱动实际使用的 K_h、F_h 与"发生率面集 + 同被积函数独立装配"逐项对照（相对差 ≤1e-12 量级）；不过不许进算例开发 |
| S3 | 纯冷却交叉路径对照 | 同子网格、同 Robin、同初温场：驱动热步进在 Q≡0 构造下（构造方式开发时定并写入测试注释，候选：J_s 给零激励使 Q=0）与 `transient_heat_tet10`（f=0、同 robin）在同一网格独立跑纯冷却，节点温度对照（两边同为离散解，相对差 ≤1e-9 量级） |
| S4 | 三方对账恒等式 | 短算例（绝热 + 冷却各一）：`balance_rel` 新口径应在求解器精度量级（阈值按首跑写死）；绝热路 E_loss 恰为 0.0 |
| S5 | 冷却方向性冒烟 | 同参数双跑（冷却开/关）：终点表面节点温度低于芯部、Tmax 严格低于绝热路、E_loss > 0（只查方向与符号） |

  区间 peak_engaged 为真。若算例设计确实做不到（区间
  ΔT 与峰宽不可比），开发报告中须**明示 A4 交互检查为

## 5. 不做事项

- 不做 B（stagger 判据研究、推荐 tol、`stagger_converged`
  标志）——排 v2.3，理由见 §1.2；本版不顺手改 stagger 任何
  默认与记录字段。
- 不做 C（材料律接口）——排 v2.4 或实测数据到位时触发，
  理由见 §1.2；本版不引入律对象、不改五支律函数的签名。
- 不做 h 随时间/温度变化（沸腾曲线、喷淋启停时序、分区
  喷淋）：只做恒定等效口径、全部外表面。时变 h 破坏
  "K_h 一次装配"结构，另行立项评估。
- 不做非均匀初温场 / 断点续算式 T0：驱动 `T0` 仍为均匀
  标量。因此"先加热、后冷却"的两段工艺在单次调用内仍不可
  达（调用方也不能以终态温度场续跑）——如实列为已知边界，
  是否立项留后续版本决定，不在本版顺手扩签名。
- 不做 Neumann 热流接入耦合驱动、不做 Dirichlet 表面温度；
  不做 k_th(T)；不做热应力链、Newton 法、时域非线性、谐波、
  磁滞、Nédélec 边元（均按既定后置口径）。
- 不改 `em3d_tet10.py` 与 v1.7–v2.1 既有函数的数值行为；
  不改默认 `em_every=5`、`stagger_iter=1`、`em_tol=1e-3`
  （em_every 默认值问题见 §6 第 1 条，明确不捆绑）。

## 6. 风险与依赖

1. **与 em_every 默认值挂起提议的关系（明确切割）**：把
   `em_every` 默认值由 5 改为 1 的提议仍在单独挂起评审中。
   v2.2 **不捆绑**该变更：不改默认值、不以 A 的任何算例结论
   为该提议背书或反对。A 的开发与验收在默认 `em_every=5`
   下成立；A4 中若出现与区间冻结粒度相关的现象，按 v2.1
   scope 的粒度警示口径如实记录即可，处置归该提议的单独
   评审，不在本版内顺手改默认。
2. **v2.1 已知限制继续有效**：默认工况下单区间温升
   （~500 K）≫ 峰宽（25 K）时焓峰被动力学跳过的问题不因
   A 而解；冷却主导阶段温变慢、跳过概率降低只是定性预期，
   不许写成"A 修复了 v2.1 限制"。v2.2 scope（入库版）须设
   已知限制节重申此点，A4 的断言亦只取方向性。
3. **子网格表面登记的薄壁陷阱**：见 §2.2。`_boundary_faces10`
   由节点集导面，发生率面集登记的节点集在薄壁几何下可能让
   个别内部面被误判为边界面——S2 守门断言（含薄壁几何）就
   是为此设；若守门不过，按 §3 的处置口径改为发生率面集
   直接装配并记录，不许带病进算例。
4. **冷却拉长时间尺度**：有冷却后热平衡时间尺度拉长，
   A3 稳态算例与真实淬火时长算例的成本上升；同时 cp 常数
   段（峰关闭时）与恒定 k_th 等既有简化在长时窗口的影响
   比绝热短时算例更大。缓解：算例仍以可跑完为限设计并
   明示口径，定量结论只在所跑窗口内声明。
5. **数值环境口径**：交卷以管家云端（numpy 2.5.4 /
   python3.13）复跑为准；本地 numpy 差异按既有教训处理
   （hasattr 惰性分支）。新代码如需积分/特殊函数，先查此
   口径。措辞纪律：全部数字标"仿真输出/仿真结果"，仿真
   输出永不称"实测"（本机计时可写"本机实测"）。
6. **时长与算力**：全量测试时长预计超 v2.0（§4.2 已述）；
   开发机只跑冒烟，全量交管家云端。开发启动时点避开其他
   在途重算例队列。

## 7. 已知限制（R1 修订：措辞边界写死）

本版的真实口径 = **恒定等效 h、全部外表面、无分时启停、
无非均匀初温场/断点续算**。因此：

1. **不能表述完整淬火工艺**。先热后冷的两段工艺循环
   （喷淋在加热段后开启、沸腾曲线随温变 h、分区喷淋）
   在本版内不可达：h 不随时间变化（时变 h 破坏 K_h 一次
   装配结构，另行立项评估），`T0` 仍为均匀标量（不做非
   均匀初温场，单次调用内"先加热、后冷却"不可达，调用
   方也不能以终态温度场续跑——§5 已列）。§1.1"缺失一半"
   的说法已降格为"补上冷却段（恒定等效 h 简化口径）"，
   不得升格回"完整淬火工艺"。
2. **示例值引用纪律**：`cooling={"surface": (5000.0, 20.0)}`
   中 h = 5000 W/(m²·K) 为模型假设示例量级、非实测。
   开发报告、测试注释、README 引用时每次须带"模型假设
   示例值、非实测"的声明；README 与入库版
   docs/v2.2_scope.md 须同步本节限制。
3. **v2.1 已知限制继续有效**（重申 §6 第 2 条）：默认工况
   下单区间温升 ~500 K ≫ 峰宽 25 K 时焓峰被区间冻结跳过
   的问题不因 A 而解；冷却主导阶段温变慢、跳过概率降低
   只是定性预期，不许写成"A 修复了 v2.1 限制"。
