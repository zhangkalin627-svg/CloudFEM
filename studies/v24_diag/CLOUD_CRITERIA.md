## 0. 诊断量时间对齐口径（评审条件⑦，逐项写死）

驱动主循环（induction3d_tet10.py）：每 EM 区间内 stagger pass
s=0,1,… 依次执行——① EM 解（输入场 T_est，输出 em_info 含该
pass 的割线 μr）；② 热步进（从区间起始场 T_start、源项 F_Q）
得 T_new；③ dT_stagger = max|T_new(s) − T_new(s−1)|（首 pass
无 dT）；④ T_est = T_new 供下一 pass。区间结束后 T = T_trial
（末 pass 的 T_new），Te = elem_temps(T)。

| 诊断量 | 取样点（写死） | 现有口径声明 |
|---|---|---|
| frac_above_Tc | **区间末温度场**：该区间最后一个 stagger pass 完成后的工件单元温度 Te；Tc 取驱动现行律参数 `t_curie`；**体积分数** = Σ(Te > Tc 的单元体积) / 工件总体积 | 现有 history 同名字段为**单元计数分数**（np.mean(Te > t_curie)），v2.4 诊断记录改用体积分数；报告中两字段区分声明，不混用 |
| mu_r_agg | **该区间最后一个 stagger pass 的 EM 解所用割线 μr**：该 pass 的 em_info["mu_r_elem"][iron_idx]（按该 pass 输入温度场 T_est 算得）；三元组 (min, **体积加权均值**, max) | 现有 history.mu_r_iron_mean 为计数均值；v2.4 诊断记录改用体积加权均值。submesh 单元 i ↔ iron_idx[i]（掩码顺序保留），体积取自 sub.element_volumes() |
| stagger_dT_seq | 该区间每次 pass 的 dT，按 pass 顺序，长度 = 该区间实际 passes 数；首 pass 无 dT（记为缺失）；标量 stagger_dT 保留 = 末 pass 值，与现状语义一致 | —— |

**不同态声明（评审条件⑦后半）**：mu_r_agg 取自末 pass 的
**输入**温度场（T_est），frac_above_Tc 取自末 pass 的**输出**
温度场（区间末场）；两者在时间上相邻但**不同态**。
v2.4 诊断只许**并列记录**，不作时序因果断言；
"居里穿越—μr 塌缩—不收缩"的关联判定走 D4 三态措辞。

## 1. D1 逐位复现（硬判据；评审条件③⑥）

采用条件⑥二选一中的 **"≤ 既定求解精度量级"版**（管家建议取后者），
量化阈值如下（不取"相对差 0"）：

- 比较对象（同算例同参数、同机）：
  (a) 诊断关 vs main@7f57cc7 现状基线；
  (b) 诊断开 vs 诊断关。
- 比较量与阈值：
  - Tmax（°C）、E_in（J）：相对差 **≤ 1e-12**；
  - history 既有键：stagger_passes / em_iterations / em_converged
    逐位一致（整数/布尔精确相等）；stagger_dT、P、T_elem_mean/max
    相对差 ≤ 1e-12（分母为 0 时改用绝对差 ≤ 1e-14）；
  - balance_rel 维持既有口径（≤ 4.4e-16 量级），不放宽。
- 阈值依据：balance_rel ≤ 4.4e-16 为离散能量对账量级（~机器
  ε 量级）；Tmax 量级 ~1e3 °C。阈值取相对 1e-12，即对账量级的
  10^4 倍——覆盖多热步累积舍入；诊断只增记录、不动求解路径，
  任何真实数值路径改动（如 v2.0 em_every=5→1 的 T +0.51%）
  都会远超此阈值，故 1e-12 既是保守量级又是有效判据。
  **不拍脑袋取 0**：1e-12 的依据如上逐条可溯。

不过此条，本版不交卷。

## 4. D4 未决点②三态判定（措辞写死；评审条件"三态允许
数据不足以判定"同步）

报告对"区间3 不收缩与居里穿越 μr 塌缩相关"只许下三态之一：

- (a) **数据支持**：区间3 的 frac_above_Tc / μr 变化与不收缩档位
  在时序上对应、且其余收缩区间无同等程度变化；
- (b) **数据不支持**：区间3 诊断量与收缩区间无可辨差异，
  或不收缩出现在 μr 无显著变化的区间；
- (c) **数据不足以判定**：诊断量分辨率/算例覆盖不足以区分
  （合法结论，不算失败；A1 级只有 4 区间、单算例，落 (c)
  不触发扩矩阵——扩矩阵属出数后调整，须重新送审）。

三态之外不许写"证明机理"；即便 (a)，措辞只到"与推断方向一致、
获数据支持"，因果断言仍标推断（相关 ≠ 因果，单算例无对照实验）。
